# UI — Codex

## Options for `/plan`:
```text
 Implement this plan?

› 1. Yes, implement this plan          Switch to Default and start coding.
  2. Yes, clear context and implement  Fresh thread. Context: 37% used.
  3. No, stay in Plan mode             Continue planning with the model.

  Press enter to confirm or esc to go back
```

The menu has no free-text acceptance note or denial-reason path. “No, stay in Plan mode” returns to the
ordinary prompt box; its observed hook sequence was `Stop`, then an ordinary `UserPromptSubmit`, with no
`exit_plan_mode` / `ExitPlanMode` event. The two acceptance paths still need independent payload captures.

“Yes, clear context and implement” is the Codex-specific modifier to preserve if and only if a matching
acceptance event exposes an explicit, stable context-clear field. Starting a fresh session alone is not enough
evidence to infer that tag.
