# UI — Claude

## Options for `/plan`:
```text
 Claude has written up a plan and is ready to execute. Would you like to proceed?

   1. Yes, and use auto mode
   2. Yes, manually approve edits
 ❯ 3. Tell Claude what to change
      shift+tab to approve with this feedback

 ctrl+g to edit in nano · /path/to/plan/file/in/the/claude/config/dir/something/foobar.md
```

## Options for commands
```text
 This command requires approval

 Do you want to proceed?
 ❯ 1. Yes
   2. Yes, and don’t ask again for: python3 *
   3. Yes, and switch to auto mode · auto mode handles these prompts for you
   4. No

 Esc to cancel · Tab to amend
```
Note: _Tab to amend_ exists only on the plain _1. Yes_ and _4. No_.

#### After Tab
```text
 This command requires approval

 Do you want to proceed?
 ❯ 1. Yes, <cursor>and tell Claude what to do next
   2. Yes, and don’t ask again for: python3 *
   3. Yes, and switch to auto mode · auto mode handles these prompts for you
   4. No

 Esc to cancel
```
