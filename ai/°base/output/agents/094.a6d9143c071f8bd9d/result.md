**Schema for `http`-type servers** (`ai/settings/mcp.schema.json`), which is exactly what you need for the sync_todo Streamable HTTP server:
```json
"servers": {
  "additionalProperties": {
    "properties": {
      "enabled": { "type": "boolean", "default": true },
      "type": { "type": "string", "enum": ["stdio", "http"] },
      "tools": { "type": "array", "items": {"type": "string"} },
      "cmd": { "type": "array", "items": {"type": "string"} },
      "url": { "type": "string", "format": "uri" },
      "headers": { "type": "object", "additionalProperties": {"type": "string"} }
    },
    "required": ["type"],
    "allOf": [
      { "if": {"type":"const stdio"}, "then": {"anyOf":[{"required":["cmd"]},{"required":["tools"]}]} },
      { "if": {"type":"const http"}, "then": {"required":["url"]} }
    ]
  }
}
```
So an admin-token-gated HTTP server entry should look like:
```json
"sync_todo": {
  "enabled": true,
  "type": "http",
  "url": "https://<sync-todo-host>/mcp",
  "headers": { "Authorization": "Bearer <ADMIN_TOKEN>" }
}
```
(exact header name depends on how sync_todo's FastAPI mount checks the admin token — grep its backend for the auth-dependency header name before finalizing).
